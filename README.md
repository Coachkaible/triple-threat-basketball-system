# Triple Threat Basketball System

Player-facing interactive website for the **Triple Threat Base Offensive System**.

## Current build
- 29 teaching steps
- Base Motion + Pressure Release
- One-screen WATCH IT presentation
- Smooth Previous / Next / swipe navigation
- Teaching autoplay: 20 seconds per step
- LEARN MY JOB roles for players 1–5
- 18-question TEST ME section
- Mobile-first layout for players and families

This repository is intended to be connected to Cloudflare Pages for automatic deployment.
